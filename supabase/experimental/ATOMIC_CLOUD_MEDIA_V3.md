# Atomic production media integration
Follow-up to 9f00dd1. SQL verifies owner-bound path, asset ID digest and Storage object existence/size. Existing unchanged legacy media is not reuploaded. Local pull checks SHA-256 for new paths and removes previously indexed unchanged assets absent from remote manifest with rollback snapshot; unknown local assets retained. No physical object deletion: old and abandoned staged objects retained for later verified garbage collection. Existing signature-based change detection retained. Concurrent revision conflicts involving media remain blocked; no legacy writer fence yet. Test Storage is simulated; real Storage network acceptance not performed.
